Data Safety — ForgeFlow

Base para preencher a seção Data Safety da Google Play.

Este documento é um guia inicial e deve ser revisado antes da publicação oficial.

1. O app coleta dados?

Sim. O ForgeFlow pode coletar dados fornecidos pelo usuário e dados gerados durante o uso do aplicativo.

2. Tipos de dados possíveis

Informações pessoais:
- nome;
- e-mail;
- foto/avatar, se enviada pelo usuário.

Saúde e fitness:
- treinos;
- exercícios;
- séries;
- cargas;
- repetições;
- notas;
- histórico;
- progresso;
- metas;
- fotos de progresso, se enviadas.

Atividade no app:
- eventos de login;
- último acesso;
- configurações;
- uso de funcionalidades.

Arquivos e fotos:
- fotos de progresso;
- imagens/avatar, se enviadas pelo usuário.

3. Finalidade do uso

- funcionalidade do aplicativo;
- gerenciamento de conta;
- acompanhamento de treino;
- analytics internos;
- segurança;
- suporte;
- recuperação de conta.

4. Dados são vendidos?

Não.

5. Dados são compartilhados?

Podem ser processados por provedores necessários ao funcionamento do app, como hospedagem, banco de dados, autenticação, armazenamento de imagens e envio de e-mails.

6. O usuário pode solicitar exclusão?

Sim. A conta pode ser excluída pelo app ou por solicitação de suporte.

7. Dados são criptografados em trânsito?

O app deve ser usado em HTTPS em produção.

8. Observação

Antes da publicação, revise este conteúdo conforme as configurações reais de produção, provedores usados e público-alvo escolhido na Play Store.
