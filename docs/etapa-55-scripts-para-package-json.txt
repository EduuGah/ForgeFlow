Adicione estes scripts no package.json da raiz do frontend, se ainda não existirem:

{
  "deps:audit": "node scripts/frontend-dependency-audit.mjs",
  "size:report": "node scripts/frontend-size-report.mjs",
  "check:frontend": "npm run deps:audit && npm run size:report"
}

Uso:

npm run deps:audit
npm run size:report
npm run check:frontend

Atenção:
- Não remova dependências automaticamente.
- Revise o resultado do deps:audit antes de apagar qualquer pacote.
- Algumas libs podem ser usadas por configuração, plugins ou scripts e não aparecerem nos imports.
