# ForgeFlow Share V16

## Foco desta versão
- Simplificação visual do editor.
- Menos opções abertas ao mesmo tempo.
- Preview mais fácil de acompanhar enquanto o usuário ajusta o card.

## Melhorias
- Controles reorganizados em menus suspensos:
  - Visual do card
  - Figurinhas
  - Foto de fundo
  - Mensagem
- Resumo rápido no topo com formato, template, quantidade de figurinhas e item selecionado.
- Preview fixo (sticky) para reduzir a necessidade de rolar de volta para conferir alterações.
- Footer de ações mantido visível com comportamento sticky.
- Submenu separado para alinhamento rápido.
- Menu de edição da figurinha selecionada mantido dentro do fluxo de figurinhas, reduzindo poluição visual.
